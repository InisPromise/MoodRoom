# MOOD ROOM
## What is Mood Room?
Mood Room is a device which takes in user input, calibrates a variable user comfort level based on this input, then outputs this comfort level via an RGB LED. 

## How to set up Mood Room?
1) Build circuit following the hardware setup guide (coming soon!)
2) Clone this repostiory to your local machine
3) Program Arduino-compatible microcontroller with the code provided

## How to use Mood Room?
Before turning on Mood Room, ensure you are wearing the EEG and heartbeat sensor. 

After turning on Mood Room device, user will be welcomed and prompted to choose a color mode (options include warm and cool. Default is warm). 

If user is correctly wearing the wearables, LED will change states according to user comfort level. 

To immediately turn off Mood Room, please press the emergency off button. 

## A Note on Autonomy
Mood Room is meant to be used to outwardly reflect the user's inner emotional state. The underlying philosophy is that while sometimes we as humans
are dishonest with ourselves about our emotions, our biological signals portray, more or less, the truth of our feelings. Mood Room is meant to harness
these signals and output them via an LED in order to encourage the user to confront their true emotions. It is not meant to assist in the processing of these emotions. You as the user have a responsibility to sit with your emotions, analyze them, and work through them in a healthy way. 

And, while the Mood Room team has gone through great lengths to produce accurate emotional readings, at the end of the day, you must trust your own mind. Mood Room may not always be completely accurate. Mood Room developers encourage users to take the LED readings with a grain of salt, trust themselves, and work through emotions responsibly.
